# 北辰燒餅｜GitHub Pages 靜態網站

這是一個不需要後端或建置工具的單頁行銷網站，直接使用 HTML、CSS 與原生 JavaScript，適合部署到 GitHub Pages。

## GitHub Pages 部署

1. 將 `index.html`、`styles.css`、`script.js` 推送到 GitHub repository。
2. 開啟 repository 的 **Settings > Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**。
4. 選擇 `main` 分支與 `/ (root)` 資料夾後儲存。

網站中的圖片目前使用 Unsplash 圖片 URL；若要完全掌握素材與效能，可將店家實拍圖放入 `images/`，再替換 `index.html` 中的圖片網址。
